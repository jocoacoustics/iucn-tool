Instala el conector IUCN para continuar

El conector es necesario para consultar IUCN API v4 desde tu navegador. Solo debes instalarlo una vez.

  1. Descarga el conector (.zip).
  2. Descomprime el ZIP en una carpeta permanente.
  3. Abre la página de extensiones de tu navegador.
  4. Activa Modo de desarrollador.
  5. Haz clic en Cargar descomprimida y selecciona la carpeta que contiene manifest.json.
  6. Vuelve a IUCN Tool y recarga la página.
Descargar conector (.zip)

Si el navegador no permite abrir su página interna automáticamente, la ruta se copiará para que la pegues en la barra de direcciones.

Cuando el conector esté disponible, esta ventana desaparecerá automáticamente y se habilitará IUCN Tool.
